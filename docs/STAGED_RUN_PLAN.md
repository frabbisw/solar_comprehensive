# Staged revision run plan

This is the recommended order for the first GPT-6 Luna pass. It deliberately
finishes one complete execution before adding independent repetitions.

All commands assume the root `.env` contains:

```text
OPENAI_MODEL=gpt-6-luna
OPENAI_REASONING_EFFORT=none
OPENAI_REASONING_MODE=standard
REVISION_COMMON_TEMPERATURE=0.8
FLOWGEN_TEMPERATURE=0.8
```

## Stage 1: full RQ1 Luna temperature study

Run all 343 SocialBias-Bench tasks, five independent snippets per task, at all
five temperatures used in the paper: 0.2, 0.4, 0.6, 0.8, and 1.0.

```bash
bash scripts/run_rq1_full.sh luna_rq1_run1
```

This produces 343 x 5 x 5 = 8,575 Luna generations. The original/default
prompt is used at every temperature. Solar evaluation runs automatically for
all five temperatures.

## Stage 2: RQ4 once

Run all 343 tasks through the Developer baseline and up to three FMA rounds:

```bash
bash scripts/run_rq4_once.sh luna_rq4_run1
```

The command evaluates Developer, R1, R2, and R3 with Solar.

## Stage 3: small RQ3 pilot

Run the first five tasks through all 12 RQ3 configurations:

```bash
bash scripts/run_rq3_sample_once.sh luna_rq3_pilot5_run1 5
```

Inspect the pilot before the full RQ3 run. Confirm that FlowGen completes, final
outputs are extracted, and Solar reports executable outputs.

## Stage 4: full RQ3 once

```bash
bash scripts/run_rq3_once.sh luna_rq3_run1
```

This runs all 12 configurations on all 343 tasks once. It is resumable: after an
interruption, rerun the exact same command and completed task outputs are
skipped.

## Stage 5: RQ2 all revision prompt styles

Run the six revision conditions at temperature 0.8:

```bash
bash scripts/run_rq2_once.sh luna_rq2_run1 luna_rq1_run1
```

The six conditions are Default, Pure CoT, Fairness-only, Positive-role-only,
CoT+fairness, and Positive-role+CoT+fairness. The RQ2 Default prompt is
byte-for-byte identical to the original RQ1 Default prompt, so the command
reuses the five Luna outputs per task already generated by RQ1 at t=0.8.
The other five styles are newly generated. Thus the RQ2 table contains all six
Luna styles while avoiding 1,715 duplicate API calls.

## Stage 6: later independent repetitions

After inspecting run1, add independent RQ3/RQ4 runs with new IDs:

```bash
bash scripts/run_rq3_once.sh luna_rq3_run2
bash scripts/run_rq4_once.sh luna_rq4_run2

bash scripts/run_rq3_once.sh luna_rq3_run3
bash scripts/run_rq4_once.sh luna_rq4_run3
```

RQ1 and RQ2 already contain five independent generations per task per
configuration. The reviewers' repeated-run request is most directly addressed
by the additional RQ3/RQ4 executions.

## Usage/cost after any stage

```bash
python scripts/summarize_usage.py
```
